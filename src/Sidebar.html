Metabase to Sheets

Copies one saved question into this sheet. Data only moves from Metabase to the sheet.

The https address of your Metabase, with no path. Example: https://example.metabaseapp.com

From Metabase: Admin, Settings, Authentication, API keys. The key stays in your Google account. It is not written to the sheet. How to create an API key

The number in the question URL. Example: 42 from /question/42.

The schedule runs as the Google account that saved it, and uses that account's API key. Hourly, every 6 hours, and daily are approximate. Apps Script chooses the exact minute.

Sync replaces the cells on the chosen sheet. If the new result is smaller, leftover rows are cleared.
