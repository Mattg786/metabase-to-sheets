A direct path from question to cells.

The add-on uses your Metabase API key to request the JSON result of one saved question. It writes the headers and rows into the sheet you choose.

Small scope by design.

The add-on reads the Metabase result and writes to the selected current spreadsheet. It does not write back to Metabase. Your Metabase API key stays in Google Apps Script UserProperties.
