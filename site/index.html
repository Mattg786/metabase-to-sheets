Copy a saved Metabase question into Google Sheets

The add-on reads the result of one saved question and writes it into a sheet tab, starting at cell A1. Run it with Sync now or on a Daily schedule. Pro adds Hourly and Every 6 hours.

How to set it up

  1. Create a Metabase API key

    In Metabase, open Admin, Settings, Authentication, API keys. Put the key in a group that can only view the questions you want to sync.

  2. Open the sidebar

    In the sheet, choose Extensions, Metabase to Sheets, Open. Enter your Metabase address, the key, and the question ID from a URL such as /question/42.

  3. Choose a tab and a schedule

    Pick the tab to write to, then Manual only or Daily. Save, then press Sync now to check it works.

What it reads and writes

It reads one saved question from your Metabase and writes to the spreadsheet you have open. It never writes back to Metabase. Each sync replaces only the cells it wrote last time, so your own cells outside that block stay as they are.

Your API key is saved to your Google account for this add-on. It is not written into the sheet, so other editors cannot see it. Sheet data never passes through our servers.
