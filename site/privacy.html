Privacy

How the add-on and this website handle your data.

Google API data

Metabase to Sheets uses information received from Google APIs in line with the Google API Services User Data Policy, including its Limited Use requirements. This is a product commitment, not a Google certification.

The add-on only reads and writes the current spreadsheet. It needs four permissions: the current spreadsheet, to write the result into the tab you choose; the sidebar; outside requests, to reach your Metabase and the licence check; and triggers, to run schedules.

Metabase data and your API key

The add-on sends the site address, question ID, and your Metabase API key to your Metabase over https. The key is saved to your Google account for this add-on only. It is not written to the sheet or to logs, and other editors of the sheet cannot read it. Scheduled syncs use the saved settings and that account's key.

The add-on reads the result of the selected question and writes it to the selected tab. It does not write back to Metabase. Each spreadsheet has one saved sync. We do not store spreadsheet contents on our servers. The add-on never sends sheet rows or your Metabase key to the licence check.

Licence and payments

If you enter a licence key, the add-on sends only that key to the licence check. The check asks Stripe whether the matching subscription is active and is for Metabase to Sheets Pro. Stripe keeps the payment, subscription, and licence records needed for that. The payment confirmation page shows a key only after the server confirms the payment.

After a successful check the add-on remembers the result for up to 24 hours, so it does not check on every run. If the licence server cannot be reached, the last successful result can be used for up to 7 days from that check. If the server says a subscription is not active, Pro stops at once. This website never handles card details. Pro is not on sale yet; you can join the waitlist on the pricing page.

Hosting, logs, and support

This website and the licence check run on Cloudflare Workers. Cloudflare may keep request logs under its own controls.

If you join the waitlist, we store your email, the optional note you write, the time you joined, and an optional source tag from the link you used. We use that only to tell you when the add-on launches and when Pro goes on sale. Those emails are stored in a Cloudflare D1 database bound to this site. Email mattgalea@mail.grokbot.com from that address to ask us to delete your waitlist entry.

Support is at mattgalea@mail.grokbot.com. Support uses what you choose to send to fix setup, access, payment, or licence problems. People do not read product data except with your consent for support, for security work, or when the law requires it. Data is not sold and is not used for advertising.

Removing access and deleting data

To stop scheduled requests, choose Manual only and Save. To clear the saved Metabase key, tick Remove saved API key and Save, which also turns the schedule off. Removing a saved licence key clears the key and its remembered check, and returns the add-on to Free. None of these delete cells already synced.

You can review or remove the add-on's access at Google Account connections. Removing access or uninstalling the add-on does not delete cells already synced. A Stripe subscription can be cancelled through Stripe, after which the licence check fails. The add-on keeps no server database. Hosting logs, Stripe records, and support email follow those providers' retention settings. To ask about access to or deletion of support information, email the support address above.

Changes and contact
