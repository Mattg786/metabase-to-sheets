Privacy

What moves, where it stays, and why.

This statement describes the current add-on and launch website. It does not claim Google verification or Marketplace publication.

Google API data

Metabase to Sheets uses information received from Google APIs in accordance with the Google API Services User Data Policy, including its Limited Use requirements. This is a product commitment, not a Google certification.

The add-on only reads and writes the current spreadsheet. It uses current-spreadsheet access to write the result of one saved Metabase question into the selected sheet. It uses Apps Script container UI for the sidebar, external requests for Metabase and licence checks, and Apps Script triggers for schedules.

Metabase data and credentials

The add-on sends the site URL, question ID, and Metabase API key to your Metabase host over HTTPS. The API key is stored in Apps Script UserProperties for the Google account that entered it. It is not written to the sheet, document properties, or the Apps Script log. Scheduled syncs use the stored spreadsheet configuration and that account's saved key.

The add-on reads the JSON result of the selected question and writes it to the selected sheet. It does not write back to Metabase. The current data model saves one sync configuration per spreadsheet. We do not store spreadsheet contents on our servers. The add-on does not send sheet rows or Metabase credentials to the licensing service.

Licence and payments

If you enter a licence key, the add-on sends only that key to the configured licence endpoint. The endpoint verifies the key against Stripe subscription metadata, including the configured product price and active subscription status. Stripe stores payment, subscription, and licence metadata needed for that check. The success page only displays a key after the server verifies the paid Checkout Session and signed webhook fulfilment.

The Apps Script licence cache is stored per Google user for up to 24 hours after a valid check. If the licence server is unreachable or returns malformed data, the last valid active result can be used for no more than 7 days from its original check. An explicit inactive or configuration response revokes Pro immediately. The outage fallback does not extend its timestamp. The website does not handle card details. It links to a Stripe-hosted Payment Link when that link has been configured.

Hosting, logs, and support

The launch website and serverless API are prepared for configurable hosting. Hosting providers may keep request logs under their own controls. The intended temporary base is https://metabase-to-sheets.vercel.app, but it is not claimed as live or Google verified here.

Support is available at mattgalea@mail.grokbot.com. Support may use information you choose to send to diagnose setup, access, payment, or revocation issues. Humans do not read product data except with support consent, for security work, or when required by law. Data is not sold and is not used for advertising.

Revocation and deletion

To stop future scheduled requests, choose Manual only and save, then select Remove saved API key if you want to clear the stored Metabase key. Clearing the saved licence key removes the licence key and its cache from UserProperties, and returns the add-on to the free plan. Removing the saved API key turns off the schedule. These actions do not delete cells that were already synced.

You can review or remove the Google account connection at Google Account connections. Removing the connection or uninstalling the add-on does not delete cells already synced into a spreadsheet. A Stripe subscription can be cancelled through the payment provider's controls, after which an inactive subscription fails the licence check. The add-on does not keep a server database. Hosting request logs, Stripe records, and support email are subject to the controls and retention settings of those providers. To ask about access or deletion of support information, contact the support address above.

Changes and contact

The product may update this statement when the data flow changes. Contact mattgalea@mail.grokbot.com with privacy questions.
