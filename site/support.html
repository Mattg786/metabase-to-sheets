Before your first sync

  1. Create a Metabase API key in Administration, Settings, Authentication, API keys.
  2. Find the saved question ID in a URL such as /question/42.
  3. Open the add-on sidebar from Extensions, Metabase to Sheets, Open.
  4. Enter the HTTPS Metabase site URL, API key, question ID, and target sheet.
  5. Choose Manual only or Daily, then save. Sync now runs immediately.

Schedules and Pro

The free plan has one saved sync per spreadsheet. Manual sync and Daily are available without licensing. Hourly and Every 6 hours require a verified Pro licence. The sidebar checks the licence before saving a restricted schedule and again before a scheduled run.

Common errors

  • Wrong key: Metabase returned 401. Create or paste a key with access to the question.
  • No access: Metabase returned 403. Ask a Metabase administrator for permission to the question.
  • Missing question: Metabase returned 404. Check the question ID and site URL.
  • Unreachable host: confirm the HTTPS URL and network access. The sheet keeps its previous cells.
  • Licence not active: check the key and the Stripe subscription. The price must be the configured product price.

Stop a schedule

Choose Manual only and save. To remove stored access, select Remove saved API key and save. A cleared key turns off the Metabase schedule. Licence keys can be cleared in the same sidebar field. Clearing a licence key removes its per-user key and cache. These actions do not delete cells already synced.

Google account access

Review or remove the account connection at Google Account connections. Removing the connection or uninstalling the add-on does not delete cells already synced.
