Support

Setup steps, common errors, and how to get help.

Set up the add-on

The add-on is not on the Marketplace yet, so you install it from the source code. The setup guide in the README walks through it with clasp and a test sheet.

  1. Create a Metabase API key in Admin, Settings, Authentication, API keys.
  2. Find the saved question ID in a URL such as /question/42.
  3. In the sheet, choose Extensions, Metabase to Sheets, Open.
  4. Enter the https Metabase address, the API key, the question ID, and the tab to write to.
  5. Choose Manual only or Daily, then Save. Sync now runs straight away.

Choose a safe API key

Metabase gives each API key the permissions of the group it belongs to. Create a group that can view only the collections holding the questions you sync, and put the key in that group. Do not use a key in the Administrators group. If a key leaks, revoke it in Metabase and save a new one in the sidebar. See Metabase API keys.

Schedules and Pro

Free includes Sync now, Manual only, and Daily. Pro adds Hourly and Every 6 hours. Both keep one saved sync per spreadsheet. The add-on checks the licence when you save a Pro schedule and again before each scheduled run.

Common errors

Metabase rejected the key (401)
Create a new key, or paste the key again. The sheet is not changed.
No access to the question (403)
Ask a Metabase admin to give the key's group view access to that question's collection.
Question not found (404)
Check the question ID and the site address.
Metabase cannot be reached
Check the https address and that Metabase is reachable from the internet. The sheet keeps its previous cells.
Too many rows or columns
Results over 100,000 rows or 2,000 columns are refused before the sheet changes. Filter the question in Metabase.
Licence key not recognised
Copy the key again from your payment confirmation page, with no spaces.

Stop a schedule or remove keys

Choose Manual only and Save. To remove the Metabase key, tick Remove saved API key and Save. This also turns the schedule off. To remove a licence key, tick Remove saved licence key and Save. None of these delete cells already synced.

Review or remove the add-on's access at Google Account connections.

Contact support

Email mattgalea@mail.grokbot.com. Include:

  • what you pressed: Save, Sync now, or a scheduled run
  • the exact message the sidebar shows
  • roughly when it happened
  • your Metabase version, if you know it

Never send your API key or licence key. No response time is promised.
